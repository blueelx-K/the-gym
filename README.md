# The Gym

Gym/Home 운동 계획 및 기록을 위한 개인용 PWA. 서버 없이 브라우저 로컬(IndexedDB)에만 데이터를 저장한다.
자세한 개발 계획은 [plan.md](./plan.md) 참고.

## 로컬에서 실행하기

ES 모듈(`<script type="module">`)과 IndexedDB를 쓰기 때문에 `file://`로 더블클릭 실행하면 동작하지 않는다.
반드시 로컬 정적 서버로 띄워서 `http://localhost:...`로 접속해야 한다.

```bash
# Python이 있는 경우
python -m http.server 8000

# Node가 있는 경우
npx serve .
```

이후 브라우저에서 `http://localhost:8000` 접속.

## 휴대폰에서 확인하기

1. PC와 휴대폰을 같은 Wi-Fi에 연결
2. PC의 로컬 IP 확인 (`ipconfig`에서 IPv4 주소)
3. 휴대폰 브라우저에서 `http://<PC의 IP>:8000` 접속

이 방식으로는 화면 확인·기능 테스트까지는 문제없지만, 아래 이유로 **"홈 화면에 추가(설치)"와 오프라인 캐싱은 정상 동작하지 않는다.**

## PWA 설치 (홈 화면에 추가)

브라우저의 Service Worker API는 **보안 컨텍스트(HTTPS 또는 `localhost`)에서만 동작**한다.
`http://<PC의 IP>:8000`처럼 평범한 HTTP로 접속하면 서비스 워커가 등록되지 않아 오프라인 캐싱과
설치가 제대로 동작하지 않는다 (`http://localhost:8000`에서는 정상 동작 — 이미 확인 완료).

실제 휴대폰에 설치해서 쓰려면 HTTPS로 서빙되는 주소가 필요하다. 가장 간단한 방법은 **GitHub Pages**
같은 정적 호스팅에 배포하는 것이다 (plan.md의 배포 전략과 동일). 배포 후에는:

- **Android (Chrome)**: 사이트 방문 시 "앱 설치" 안내가 뜨거나, 메뉴 → "앱 설치"
- **iOS (Safari)**: 공유 버튼 → "홈 화면에 추가"

두 경우 모두 홈 화면에 아이콘이 생기고, 전체 화면(주소창 없이)으로 실행되며, 한 번 방문한 화면은
오프라인에서도 열린다.
